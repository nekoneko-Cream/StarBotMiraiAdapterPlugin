## 仍未补齐或不能算完成的项目

1. 多 Mirai 实例、多 Bot 的配置列表与独立平台：当前仅现有单 Bot。
2. 真实 QQ 图片、全体 @、好友、开播/下播/动态/直播报告的逐项投递验收。
3. MySQL 数据源和真实 SMTP 告警验收。
4. 本机观察到的 MCL/QQ 发送延迟，原生接入与收发并行不能保证消除外部链路延迟。

## 不属于官方 3.0 适配器缺口

- 2.0 的排行榜、绑定、历史查询、自动迁移 Redis/订阅命令，不在本次“还原 3.0 原生”目标内。
- 语音、视频、撤回、临时会话和机器人群管理：官方 Core Sender 的当前消息协议和占位符没有这些业务入口。没有将 Mirai 能力全部暴露为新的私有 API。
- native 模式不提供插件扩展的 help/版本/订阅菜单；需要时切换 extended。

## 发送超时的含义

回环接口总等待预算小于 Core 外层 HTTP 读取超时；超时返回 HTTP 200 与非零业务 code，让 Core 执行完成/失败回调。任务携带绝对截止时间，取得锁和每次实际 HTTP 调用前检查；超时后不再开始新发送或鉴权重试。已经进入 MCL 的请求无法回滚，仍可能送达，因此不自动重发。
